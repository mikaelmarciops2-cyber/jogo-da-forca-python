# 🎮 Jogo da Forca em Python

Um jogo da forca desenvolvido em **Python** para ser executado no terminal. O projeto utiliza conceitos fundamentais da linguagem, como estruturas de repetição, condicionais, listas, funções e manipulação de strings.

## ✨ Funcionalidades

- Escolha aleatória de palavras
- Sistema de tentativas
- Exibição das letras corretas
- Validação da entrada do usuário
- Verificação de vitória e derrota
- Impede letras repetidas
- Interface simples no terminal

## 🛠️ Tecnologias

- Python 3.x

## 🎯 Como jogar

1. O jogo escolhe uma palavra aleatoriamente.
2. Digite uma letra por tentativa.
3. Se a letra estiver na palavra, ela será revelada.
4. Caso contrário, você perderá uma tentativa.
5. O jogo termina quando você descobrir a palavra ou esgotar todas as tentativas.
