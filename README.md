# Jogo da Forca em Python

Um jogo simples da forca feito em Python para rodar no terminal.

## Funcionalidades

- Escolha aleatória de palavras
- Sistema de tentativas
- Exibição das letras corretas
- Validação de entrada
- Verificação de vitória e derrota
- Impede letras repetidas

## Tecnologias usadas

- Python 3

## Como executar

Clone o repositório:

```bash
git clone  https://github.com/mikaelmarciops2-cyber/jogo-da-forca-python

Entre na pasta do projeto:
cd jogo-da-forca-python

Execute o programa:
python main.py
